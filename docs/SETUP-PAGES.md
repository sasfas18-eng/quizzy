# نسخة GitHub Pages (الويب) — حسابات حقيقية وتوليد حقيقي بلا خادم

## الرابط والنشر: GitHub وحده
- **النشر تلقائي من GitHub:** كل تعديل يُدفع إلى المستودع (فرع `main` أو `claude/**`) يُختبر كاملًا في `ci.yml`، فإن نجحت كل الاختبارات نشرته مهمة `deploy` على فرع `gh-pages` فيتحدث الموقع خلال دقيقة أو دقيقتين. لا خطوة يدوية ولا رابط آخر؛ نسخة claude.ai (artifact) لم تعد تُحدَّث.
- **أمر طارئ بلا انتظار الاختبارات:** `bash scripts/deploy_pages.sh` (الأمر نفسه تشغّله المهمة).
- **عنوان وسيط Claude بلا لمس الملفات:** من **Settings ← Secrets and variables ← Actions ← Variables** أضف `QZ_RELAY` (عنوان الوسيط) و`QZ_RELAY_MODEL` و`QZ_RELAY_RPM` (اختياري). تُطبَّق عند كل نشر. هذه **عناوين فقط، ليست مفاتيح** (انظر [`SETUP-AI.md`](SETUP-AI.md)).
- **اسم الرابط:** يتكوّن من اسم المستودع: `https://<المستخدم>.github.io/<اسم المستودع>/`. للحصول على رابط يناسب الموقع سمِّ المستودع `quizzy`: **Settings ← General ← Repository name ← `quizzy` ← Rename**، فيصير الرابط `https://sasfas18-eng.github.io/quizzy/`.
  - بياناتك المحفوظة (الملفات، الكويزات، وضع المشغل، المفاتيح على جهازك) **تبقى**، لأن المتصفح يحفظها بحسب الدومين `sasfas18-eng.github.io` لا بحسب المسار.
  - `ALLOWED_ORIGIN` على الوسيط **لا يتغير** (الأصل بلا مسار).
  - لا يحوّل GitHub الرابط القديم تلقائيًا إلى الجديد، فحدّث المفضلة. ويظل رابط المستودع القديم يحوّل إلى الجديد.
- **أفضل اسم: دومين خاص** (مثل `quizzy.example.com`): **Settings ← Pages ← Custom domain**. تنبيه: المتصفح لا ينقل بياناته المحفوظة من دومين إلى آخر، فصدّر بياناتك من صفحة «حسابي» قبل الانتقال.

GitHub Pages تستضيف ملفات ثابتة فقط، فالنسخة هنا **تعمل كلها في متصفح الطالب** وتستعين بخدمتين مجانيتين للجزأين اللذين يحتاجان شبكة:

| الجزء | كيف | يحتاج |
|---|---|---|
| **توليد الأسئلة** | **بلا مفتاح يعمل تلقائيًا توليد محلي أبسط** (من نص الملف على جهاز الزائر بلا أي طلب شبكة). وللأعمق: الصفحة تستدعي مزوّد الذكاء الاصطناعي مباشرة من المتصفح (Gemini/Groq/OpenRouter مجانًا بحدود، أو Anthropic، أو Ollama محليًا). مجمّع يوزّع الطلبات ويبطّئ تحت الحد وينتقل لمزوّد آخر عند 429. النموذج يُختار تلقائيًا مما يسمح به المفتاح | **إما** مزوّد الموقع في `config.js` (الزائر لا يحتاج شيئًا — انظر «تفعيل التوليد لكل الزوار»)، **أو** مفتاح من الزائر يلصقه مرة واحدة (بطاقة «اربط الذكاء الاصطناعي») |
| **الحسابات والحفظ** | Supabase: بريد وكلمة مرور وروابط تأكيد/استعادة، وقاعدة بيانات تعزل كل طالب عن غيره (Row Level Security) | مشروع Supabase مجاني **يُنشئه صاحب الموقع مرة واحدة** (٣ دقائق) |
| **PDF** | صفحة طباعة (`#/print/…`) ← «حفظ كـ PDF» من المتصفح (عربي سليم) | لا شيء |

بدون إعداد Supabase يعمل الموقع في **وضع الجهاز**: كل شيء يُحفظ في متصفح الطالب فقط (لا حسابات سحابية ولا انتقال بين الأجهزة)، وتظهر لافتة بذلك.

## إعداد الحسابات (مرة واحدة، لصاحب الموقع)
1. ادخل إلى https://supabase.com ← **Start your project** ← سجّل (يمكنك بحساب GitHub) ← **New project**: اختر اسمًا وكلمة مرور لقاعدة البيانات ومنطقة قريبة ← انتظر دقيقتين.
2. **SQL Editor ← New query**: الصق محتوى `supabase/schema.sql` كاملًا ← **Run**. (آمن للتكرار.)
3. **Authentication ← URL Configuration**: ضع في **Site URL** رابط موقعك على Pages (مثل `https://<user>.github.io/<repo>/`) وأضفه إلى **Redirect URLs**. بدون هذا تشير روابط البريد إلى عنوان خاطئ.
4. **Authentication ← Providers ← Email**: اتركه مفعّلًا. اختر بين:
   - إيقاف **Confirm email**: تسجيل فوري (مناسب لفصل صغير)، أو
   - إبقاؤه مفعّلًا وإعداد SMTP خاص (Authentication ← SMTP). **تنبيه:** بريد Supabase المدمج محدود جدًا بالساعة، فلا يكفي لفصل كامل دون SMTP.
5. **Project Settings ← API**: انسخ **Project URL** و**anon public key** (كلاهما عام بطبيعته؛ الأمان من سياسات قاعدة البيانات لا من إخفائهما). لا تنسخ `service_role` أبدًا.
6. افتح ملف `config.js` في جذر الموقع (فرع `gh-pages` على GitHub: زر ✏ للتعديل)، والصق القيمتين:
   ```js
   window.QZ_CONFIG = { supabaseUrl: 'https://xxxx.supabase.co', supabaseAnonKey: 'eyJ...' };
   ```
   ثم Commit. يتحدث الموقع خلال دقيقة أو دقيقتين. (أو أرسل لي القيمتين وأنا أضعهما.)

## تفعيل التوليد لكل الزوار (اختياري، لصاحب الموقع)
بلا هذه الخطوة يعمل الموقع **بالتوليد المحلي** (أسئلة أبسط، بلا مفتاح ولا حدود)، ولا يرى الزائر أي خانة مفتاح: ربط الذكاء الاصطناعي **للمشغل فقط** عبر صفحة غير معلنة `#/operator`. للذكاء الاصطناعي لكل الزوار:

1. **Claude برصيد مدفوع (الطريق الآمن): الوسيط** — اتبع [`docs/SETUP-AI.md`](SETUP-AI.md). المفتاح يبقى على وسيط Cloudflare مجاني ولا يظهر في الموقع أبدًا؛ في `config.js` يوضع **عنوان** الوسيط فقط (`relay`)، أو بأمر النشر: `QZ_RELAY=https://… bash scripts/deploy_pages.sh`.
2. **مفتاح مجاني (متقدم)** داخل `config.js` — المفتاح هنا **عام** (أي شيء في موقع ثابت يقرؤه كل من يفتح الموقع)، فلا يصلح إلا لمفتاح طبقة **مجانية** مقيَّد بعنوان موقعك (Google AI Studio ← HTTP referrers):
```js
window.QZ_CONFIG = { supabaseUrl: '…', supabaseAnonKey: '…',
  llm: [{ name: 'Gemini', kind: 'gemini', base: 'https://generativelanguage.googleapis.com', model: 'gemini-2.5-flash', key: 'AIza…', rpm: 9 }] };
```
   حدود الطبقة المجانية مشتركة بين كل الزوار؛ `rpm` يُبطّئ الموقع تحت حدّ الدقيقة.

**لا تضع مفتاحًا مدفوعًا (Claude وغيره) في `config.js` ولا في أي ملف في GitHub، ولا ترسله لأحد:** يصبح علنيًا ويُستنزف رصيدك (وAnthropic تُبطل المفاتيح المرفوعة إلى مستودعات علنية). إن تعذّر الذكاء الاصطناعي في أي لحظة (رصيد منتهٍ، وسيط متوقف) يُكمل الموقع بالتوليد المحلي تلقائيًا.

## ما الذي يضمنه ما بُني (واختُبر)
- `supabase/test/rls.test.mjs`: على **PostgreSQL حقيقي** — كل طالب يرى صفوفه فقط، لا يستطيع كتابة صفوف باسم غيره ولا نقل ملكيتها، مفتاح `anon` وحده لا يرى شيئًا، وحذف الحساب يمحو بياناته فقط.
- `static-edition/test/run_web_supabase.js`: متصفح Chromium حقيقي مع خادم Supabase وهمي: تسجيل، حفظ، استعادة الجلسة بعد إعادة التحميل، عزل بين طالبين، تغيير كلمة المرور، رابط الاستعادة، رابط تأكيد البريد، حذف الحساب.
- `static-edition/test/run_web_local.js`: بطاقة «اربط الذكاء الاصطناعي» بمفتاح يلصقه الزائر (اكتشاف النموذج تلقائيًا من المزوّد)، ثم **نقرة واحدة ← كويز جاهز**، تحقق مجمّع، تعامل مع 429، طباعة PDF، تصدير ومسح البيانات — كله عبر HTTP حقيقي مع خادم محاكى متوافق مع OpenAI.
- `static-edition/test/run_web_realistic.js`: **بلا أي إعداد من الزائر** (مزوّد الموقع من `config.js`): ملفات PPTX/PDF واقعية ← أسئلة، ونموذج يُفسد صيغة التحليل، وملف شبه فارغ يشرح الموقع لماذا لا يكفي ويعرض طريقًا للمتابعة.
- **لم يُختبر** مقابل Supabase الحقيقي ولا مزوّدي الذكاء الحقيقيين (لا حسابات لدي)، ولا يُعرف سلفًا أيّ المزوّدين يسمح بطلبات المتصفح (CORS): زر «اختبار» في الإعدادات يكشف ذلك.

## حدود النسخة
- المفتاح محفوظ في متصفح الطالب (نص). استخدموا مفاتيح مجانية/محدودة، لا مفاتيح ذات رصيد كبير.
- لا لوحة إدارة ولا بلاغات للمشرف (البلاغات تُحفظ عند صاحبها فقط).
- التوليد يعمل ما دامت الصفحة مفتوحة.
- مفتاح مزوّد الموقع في `config.js` عام بطبيعته (انظر أعلاه). لإخفائه تمامًا يلزم خادم وسيط (Supabase Edge Function أو غيره) — غير مبني بعد.
