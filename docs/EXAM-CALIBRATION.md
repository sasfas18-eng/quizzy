# معايرة كويزي على الاختبارات الحقيقية

المصدر: ٦ ملفات تجميعات من المالك (أناتومي، Introduction، مايكرو؛ ميد وفاينل)، ٢٥٢ سؤالًا.
نصوص الأسئلة لا تُرفع إلى المستودع لأنه عام؛ هنا الأرقام والخطة فقط.

## الهدف
كويزي **أعلى من الاختبار الحقيقي بدرجة واحدة، لا أكثر**، حتى يبدو الاختبار سهلًا بعده.
ولا يصل أبدًا إلى درجة المستحيل. والتجميعات هي المسطرة التي يُقاس عليها.

## ما اكتُشف
1. **قائمة المحاضرة تُسأل أكثر من مرة**: نفس الخيارات الأربعة، والوصف يتغير. مثل مراحل Benner (٣ مرات)، وأنواع الانتقال، وفيروسات الكبد، وأجزاء الجهاز التنفسي.
2. **السيناريو تغليف، والحل في كلمة مفتاح واحدة**: كيبورد ← indirect، بعوضة ← biological vector، تطعيم ← primary prevention.
3. **جملة التمهيد في Introduction تعطي التعريف**، وهو غالبًا الإجابة.
4. **في أسئلة كثيرة خيار أو خياران بعيدان جدًا**، فالقرار الحقيقي بين خيارين.
5. **الصياغة غالبًا جملة الكتاب حرفيًا** (بنك أسئلة).
6. **المشتت يقلب كلمة الاتجاه**: left/right، superior/inferior، outermost، first/last.

## ما نُفِّذ (claude-edition/engine.js)
- **صيغ جديدة، مضافة في آخر قائمة كل نوع.** الصيغ الأربع القديمة لم تتغير ولا تغيّر ترتيبها، لأن مسار التطوير يحسب كل صيغة برقم مكانها:
  - التذكّر: «عضو من قائمة المحاضرة من صفته المميزة بكلمات أخرى»، و«أي عنصرين معًا: كل عنصر في خيارين بالضبط»، و«وين يقع / أي جزء يحتويه».
  - التطبيق: «معنى المفهوم في جملة بلا اسمه ولا كلمات الإجابة، ثم: Therefore, which action/example reflects it؟».
  - السيناريو: «موقف من جملة أو جملتين فيه دليل واحد حاسم ← أي فئة / طريقة / مرحلة».
- **خطوة أعمق لنحو ٤٠٪ من الأسئلة** التي يقبل نوعها خطوة. توزَّع بالتساوي، ولا تأتي خطوتان متتاليتان، وتستمر النسبة بين الجولات. كل سؤال فيه خطوة واحدة فقط:
  - reword: الإجابة بكلمات غير كلمات الشريحة، والمشتتات بالأسلوب نفسه.
  - reverse: إن كان في السؤال اتجاه أو جانب أو طرف ترتيب، تُبنى الخيارات شبكة ٢×٢ متوازنة. هكذا لكل خيار شبيه، ولا يدل زوج على الإجابة.
  - indirect_cue: دليل الموقف يوصف بما هو أو بما يفعل، ولا يُسمّى.
  - near_order: في الترتيب، الخيارات هي تركيبات ٢×٢ لتبديلين متجاورين.
  - التفكير النقدي وNOT/EXCEPT بلا خطوة، لأنهما فوق مستوى الاختبار أصلًا.
- **قاعدة «Exam-like» في الطلب الكامل**: جملة أو جملتان، وخيارات قصيرة، ونقطة واحدة، ولا خدع.
- **فحص جديد**: إذا كانت الخيارات أزواجًا وعنصرا الإجابة هما الأكثر تكرارًا وحدهما، يُرفض السؤال لأن الطالب يستطيع أن يعدّ ويختار.
- **NOT/EXCEPT أقل**: وزنها ×٠٫٤٥. وباقي الأنواع تتبع المحاضرة كما كانت.

### منطقية الخيارات (بعد مراجعة كويز «7-CVS 2»)
- **قاعدة ٩ في الطلب الكامل:**
  - السؤال لا يذكر أي خيار أو جزءًا منه، ولا يستبعده.
  - لا خياران بمعنى واحد، مثل مرادف أو اسم آخر: «primary (essential)» و«idiopathic».
  - كل خيار خاطئ من الفئة التي يسأل عنها السؤال، وممكن الوجود (لا نسبة فوق 100٪).
  - في الخيارات متعددة الأجزاء لا يُصنع كل خيار خاطئ بتغيير جزء واحد من الإجابة.
- **المراجع الأعمى:**
  - يسمّي الخيارين المترادفين معًا، فيُعاد السؤال.
  - يعدّ القيمة المستحيلة والخيار الذي من غير فئة السؤال ضعفًا.
- **فحصان ثابتان:**
  - **السؤال يجيب نصف الخيار المزدوج:** مثل «records the heart's electrical activity» مع خيارَي «Pressure …». يكفي فيه كلمتا محتوى تميّزان الجزء الصحيح، وكلمات الاتجاه والربط لا تُحسب.
  - **الإجابة في الوسط:** كل خيار خاطئ هو الإجابة مع تغيير جزء واحد. أما الشبكة المتوازنة، وقيم الجزء الواحد الأربع، فتمرّ.

### بعد مراجعة كويز «Respiratory system»
- **الإجابة المختلفة:** يُرفض السؤال إذا كانت الإجابة وحدها باتجاه، والثلاثة الباقية باتجاه آخر. مثل «Increased» بين ثلاثة «Decreased».
- **«X فقط» و«Y فقط» والإجابة تجمعهما:** يُرفض السؤال، لأن الإجابة الجامعة تُخمَّن.
- **سؤال يقول جواب سؤال آخر عرضًا:** يُرفض إذا ظهرت ثلاث كلمات متتالية من الإجابة في سؤال آخر.
  - تُحسب العبارة كاملة، لا كلماتها مفردة.
  - مثال: «…the secreted substance that reduces surface tension» يكشف جواب «Why does the fluid … contain surfactant?».
- **أمثلة جديدة لكلود وللمراجع:**
  - «during inspiration» تعني «air flowing in».
  - الإجابة المختلفة عن الخيارات الباقية.
  - سؤال يصف عرضًا ما يسأل عنه سؤال آخر.

### قائمة ثغرات الاختيار من متعدد كاملة (كلها، لا ما ظهر في كويز واحد)
القائمة من أدلة كتابة الأسئلة المعروفة. ولكل ثغرة علاج في ثلاث طبقات:
1. **قاعدة لكلود** وهو يكتب السؤال.
2. **فحص ثابت** يرفض السؤال فيُكتب من جديد.
3. **المراجع الأعمى**: يحاول قبل الحل أن يخمّن الإجابة من الصياغة وحدها، كطالب لم يذاكر. إن أصاب الإجابة وسمّى القرينة، يُعاد السؤال. وإن فعل ذلك في أكثر من نصف الدفعة، تصير ملاحظات فقط.

| الثغرة | قاعدة | فحص ثابت | المراجع |
|---|---|---|---|
| السؤال يذكر الإجابة أو جزءًا منها | ✓ | ✓ | ✓ |
| السؤال يدل عليها بالمعنى («during inspiration» = «air flowing in») | ✓ | — | ✓ |
| الإجابة الأطول أو الأكمل | ✓ | ✓ | ✓ |
| الإجابة تشترك مع البقية أكثر (الوسط، الأزواج) | ✓ | ✓ | ✓ |
| الإجابة المختلفة (اتجاه، شكل، قوسان، فاصلة منقوطة) | ✓ | ✓ | ✓ |
| زوج متعاكس وحيد فيه الإجابة | ✓ | ✓ | ✓ |
| «X فقط» و«Y فقط» والإجابة تجمعهما | ✓ | ✓ | ✓ |
| كلمات مطلقة في الخاطئة وحدها | ✓ | ✓ | ✓ |
| النحو (a/an) | ✓ | ✓ | ✓ |
| خياران بمعنى واحد | ✓ | تطابق حرفي | ✓ |
| خيار من غير فئة السؤال أو مستحيل | ✓ | — | ✓ |
| مديات رقمية متداخلة | ✓ | ✓ | — |
| الأرقام بلا ترتيب | ترتيب تصاعدي تلقائي في العرض والملف | | |
| سؤال يكشف جواب سؤال آخر | ✓ | ✓ (ومنه العبارة العرضية) | ✓ |
| «كل/لا شيء مما سبق»، خيار يصف السؤال | ✓ | ✓ | ✓ |
| الإجابة خاطئة أو إجابتان صحيحتان | ✓ | — | ✓ (يحلّ من المصدر) |

الفحوص الخمسة الأخيرة (المتعاكس، المطلق، النحو، المديات، الشكل) لأسئلة الذكاء الاصطناعي فقط. المولّد المحلي، وهو للموقع العام المغلق، باقٍ كما كان.

### ما لم يُنفَّذ من الخطة، ولماذا
- **زيادة وزن التذكّر (×١٫٣)**: كسرت قاعدة التنوع (لا صيغة فوق ١٦٪ من الكويز). التذكّر أساس كل كويز أصلًا، فبقي على حاله.
- **الطلب المختصر للمزوّدين الصغار**: بقي كما كان حرفًا بحرف. تُطبَّق المعايرة في الطلب الكامل، وهو ما يستخدمه Claude في النسختين.
- **سؤال الحساب**: لم يُضف صيغة مستقلة، لأن «apply a value / range from the lecture» موجودة في التطبيق أصلًا.
