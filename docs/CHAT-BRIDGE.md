# الربط المجاني مع ChatGPT وClaude

الرابط الرسمي لـ«كويزي» هو <https://sasfas18-eng.github.io/quizzy/>. بعد رفع الملف يختار الطالب ChatGPT أو Claude ويسجّل الدخول في **الخدمة التي اختارها فقط**. لا يحتاج حسابًا في الخدمتين، ولا يحتاج مالك «كويزي» مفتاح API أو حصة توليد مشتركة. يبقى التوليد المحلي خيارًا احتياطيًا بلا حساب.

## لماذا الربط يدوي؟

حساب ChatGPT أو Claude في موقع المحادثة ليس API يمكن لموقع خارجي استدعاؤه. اشتراك المحادثة المجاني أو المدفوع لا يمنح «كويزي» مفتاح API، ولا يجوز للموقع قراءة جلسة المستخدم أو الردود من تبويب آخر. الربط المباشر التلقائي يحتاج API مستقلًا بشروط المزود وتكلفته.

لذلك يوفر «كويزي» جسرًا مجانيًا وصريحًا:

1. يرفع الطالب الملف ويحدد العدد والإعدادات الافتراضية أو يعدّلها.
2. يختار **التوليد عبر ChatGPT** أو **التوليد عبر Claude**؛ لا يلزمه التسجيل في الآخر.
3. يجهز «كويزي» طلبًا يحتوي صفحات المصدر المختارة، وقواعد الهوية والجودة، ومخطط JSON المطلوب.
4. ينسخ الطالب الطلب ويفتح الخدمة المختارة، ثم يسجّل الدخول بحسابه المجاني أو اشتراكه الحالي.
5. يعيد الطالب رد JSON إلى «كويزي».
6. لا يعتمد «كويزي» البنك إلا إذا اجتاز عدد كافٍ من الأسئلة التحقق؛ تصبح الأسئلة المقبولة بنك الكويز النهائي.

إذا لم يرغب الطالب باستخدام حساب محادثة، يستطيع فتح **الخيار الاحتياطي** وإنشاء أسئلة أبسط محليًا من نص الملف على جهازه.

لا يرسل «كويزي» الملف أو الطلب تلقائيًا إلى أي خدمة. خروج النص من الجهاز يحصل فقط عندما يختار الطالب النسخ ويلصقه في المحادثة.

## ما الذي يفحصه الاستيراد؟

- أربعة خيارات غير مكررة ومفتاح واحد صالح.
- وجود اقتباس الدليل في صفحة داخلة في نطاق الكويز.
- ظهور دعم كافٍ للإجابة الصحيحة في الاقتباس.
- منع «كل ما سبق» ونظائرها والقرائن الشكلية الحاسمة.
- صيغة NOT/EXCEPT والترتيب عند اختيار هذين النوعين.
- لغة السؤال وعدم استيراد سيناريو طبي لمصدر غير صحي.
- الفحص الذاتي للمشتتات، والتكرار المفهومي، وتسريب إجابة سؤال آخر.
- حفظ المفتاح بمعرف الخيار بعد خلط الخيارات.

الاستيراد لا يدّعي مراجعة بشرية ولا حلًا أعمى بنموذج مستقل؛ يسجل `blind_solver: false` و`external_chat: true`. إذا فشل الحد الأدنى يبقى الكويز المحلي كما هو، وتعود أسباب الرفض ليصححها المستخدم في المحادثة.

## الحدود

- يحتاج الطالب حسابًا متاحًا لديه في ChatGPT أو Claude، وقد تطبق الخدمة حد استخدام خاصًا بها.
- النسخ واللصق خطوة مقصودة لحماية الحساب والخصوصية وتجنب مفتاح API مدفوع.
- المحاضرة الطويلة جدًا يعبئ منها «كويزي» الطلب ضمن حد الطول، ويظهر تنبيه صريح عند استبعاد صفحات منه. وإذا وجد بنك محلي سابق يعطي صفحات أدلته الأولوية.
- لا يمكن استيراد بنك جديد بعد بدء محاولة على الكويز؛ ينشئ الطالب كويزًا جديدًا كي تبقى المحاولة مرتبطة بالأسئلة التي رآها.

## التحقق البرمجي

يغطي `static-edition/test/run_web_chat_bridge.js` إعداد الطلب، ورابطي الخدمتين، وبقاء الكويز عند رد غير كافٍ، واستيراد بنك صالح، والدليل، والمفتاح، ووسوم التحقق. ويعمل في CI بلا اتصال بـChatGPT أو Claude وبلا أسرار.
