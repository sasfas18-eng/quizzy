# كويزي داخل ChatGPT

هذا مصدر Site مع MCP وواجهة مضمّنة في ChatGPT. افتح التطبيق بأداة `open_quizzy` أو بقول «افتح كويزي» بعد تثبيت إضافة الموقع. يقرأ المتصفح PDF/PPTX نصيًا ويحفظ الصفحات المختارة في R2 تحت معرّف الطالب الذي توفره Sites؛ ثم يرسل طلب التوليد إلى نموذج المحادثة بواسطة `sendFollowUpMessage`، دون مفتاح API في الكود. لا يستدعي رابط Site المستقل نموذج ChatGPT بنفسه.

توجد قواعد المصدر والكتابة المرجعية في `knowledge/lecture_reader.py` و`knowledge/quiz_engine.py`. يعيد `get_source` هذه القواعد باختصار مع المصدر للنموذج. يتحقق الخادم من الاقتباس والصفحة، ويمنع الأسئلة عن بيانات المحاضر والأهداف والمراجع، ويفحص تكرار الغرض والنص، ويرتب الخيارات بحيث تتوازن حروف الإجابات. التحقق الآلي لا يثبت الصحة العلمية أو وجود مراجعة بشرية.

اختبر: `npm test && npm run build && npm run check:artifact`. المعاينة المحلية: `node scripts/preview.mjs --demo`. المصدر المرفوع يُحفظ كنص الصفحات المختارة، وليس نسخة ثنائية من PDF/PPTX. الصفحات المصورة أو غير المقروءة لا تدخل التوليد؛ التطبيق يبين أرقامها. استخدام الطلاب مرتبط بإتاحة إضافة Site لكل زائر وتسجيلهم في ChatGPT وحدود خططهم.
