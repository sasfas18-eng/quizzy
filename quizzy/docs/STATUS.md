# الحالة (ما نُفّذ وما اختُبر وما بقي)

## اختُبر فعليًا
- **43 اختبار آلي ناجح** (`cd backend && python -m pytest -q`): الاستخراج (PDF/PPTX/عربي/صفحة مصورة)، المدققات، المخطط، الحسابات والصلاحيات (حسابان: كل مسارات المستندات والكويزات والمحاولات والبطاقات والبلاغات ترجع 404 للغريب)، حد المعدل، استعادة كلمة المرور، المسار الكامل مع الاستئناف من «جهاز آخر»، مؤقت الاختبار على الخادم، مطابقة مفتاح PDF لترتيب العرض، رفض الأسئلة المعيبة (اقتباس مختلق، مفتاح خاطئ، التباس)، رفض التوليد بلا مفتاح بـ 503، التعديل والرجوع وقرار المراجعة، المقاييس، وتوصيل مزوّد Anthropic بعميل وهمي.
- **متصفح فعلي (Playwright/Chromium)**: تسجيل ← رفع ← اختيار نطاق يستبعد الصفحة غير المقروءة ← خطة ← توليد ← حل (تدريب) ← إعادة تحميل واستئناف ← تسليم ← نتيجة ← تنزيل PDF ← بطاقات وقلبها ← صفحة الجودة ← مستخدم ثانٍ يُحجب عن بيانات الأول ← إدارة وبلاغات ومقاييس. دون أخطاء JS. لقطات سطح مكتب وجوال راجعتها بصريًا.
- **PDF** راجعته بصريًا (إنجليزي، عربي، مختلط، مفتاح، تفسير): حروف متصلة، RTL، أقواس المصطلحات اللاتينية، عدم فصل السؤال عن خياراته.

## لم يُختبر
- **التوليد بنموذج حقيقي**: لا مفتاح في بيئة التطوير. كل اختبارات المسار استخدمت مولّدًا اختباريًا (cloze) يُوسم «محتوى اختباري» في الواجهة وPDF ويُستبعد من المقاييس. **جودة الأسئلة الفعلية، وصحة التعليمات (`prompts.py`)، ومعدلات الرفض غير مقاسة** — أول مهمة بعد وضع المفتاح: تشغيل 5–10 لكتشرات من تخصصات مختلفة ومراجعة بشرية وضبط التعليمات (الإصدار `p1.0`).
- SMTP حقيقي، حجم ملفات كبير (400 صفحة)، حمل متزامن، متصفحات غير Chromium.

## بقي / مؤجل
OCR للصفحات المصورة؛ تنفيذ الكود للتحقق؛ تصفية المقاييس حسب التخصص؛ لوحة مقارنة إصدارات التعليمات (الآن: `prompt_version` على كل سؤال وسجل تعديلات الأسئلة)؛ تحقق بريد عند التسجيل؛ المجتمع والمنافسات والمكتبة العامة والدفع (مؤجلة عمدًا).
